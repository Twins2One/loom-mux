# 女频现实题材模板(起点女生「现实生活」)

> 给【设定师】读,用来圈这本书的剧情边界。管「写什么套路」(what),不碰「怎么写得像你」(voice)。
> 参考速查,不是铁律——和你的脑洞冲突时以你为准,直接手改。
> **平台说明**:起点女生频道一级分类「现实生活」,二级 = 家与情感 / 行业人生 / 探索科幻 / 人文博览。
> 与男频「现实」(时代叙事/家庭伦理/社会悬疑/成功励志)不是一套,别混用。

## 核心爽感
普通人在真实处境里挣出一条路。爽感不是打脸,而是"这事我懂"——读者在里面看见自己或身边的人。

## 读者期待(不交付会弃书)
- **处境要真实**:钱、房、编制、户口、老人、孩子、职级——具体到能算账的程度。
- **选择要有代价**:没有便宜的好结局;每往前一步,都要拿别的东西换。
- **人物不脸谱**:婆婆不只会刁难,上司不只会压榨,各人有各人的账。
- **情绪要克制**:不批判、不说教、不灌鸡汤,把事摆出来让读者自己判断。

## 必备桥段(选用,别全塞)
- **一个具体的坎**:失业、离婚、搬家、治病、被裁员、孩子上学——开局就要落地。
- **算账**:把收入、支出、期限摆出来,让读者跟着一起紧张。
- **一次妥协**:为了活下去做出的不甘心的选择。
- **一次不妥协**:某件事上死不让步,人物的骨头在这一刻立起来。
- **关系重排**:谁在难处拉了一把,谁在难处躲开了,账目当场结算。
- **阶段性的喘息**:不是大团圆,是"这一关过去了,下一关还在"。

## 常见雷区(踩了掉粉)
- **悬浮**:月薪三千住江景房,读者立刻出戏。
- **说教**:每章都要总结人生道理,人物变喇叭。
- **开挂**:靠一个贵人/一次中奖解决所有问题,前面的挣扎全部作废。
- **反派脸谱化**:所有阻力都来自坏人,结构上就没张力。
- **只写惨**:难处堆满、没有一次喘息,读者读不下去。

## 金手指匹配
- **长什么样**:本类**基本不给金手指**。若有,多为一项具体技能(手艺/专业/信息差),
  而不是系统或超能力。
- **成长性**:技能越用越熟,人脉越走越宽,但都与现实规则一致。
- **必须有的限制/代价(防无敌)**:技能换不来运气;每一次求助都欠人情;身体与时间都是硬约束;
  越往上走,能用的手段越少而不是越多。
