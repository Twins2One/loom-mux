# 科幻空间题材模板(女频科幻言情)

> 给【设定师】读,用来圈这本书的剧情边界。管「写什么套路」(what),不碰「怎么写得像你」(voice)。
> 参考速查,不是铁律——和你的脑洞冲突时以你为准,直接手改。
> 星际 / 机甲 / 末世基地 / 虫族 都从这份起手;男频硬科幻另见《科幻》。

## 核心爽感
在一个把人当耗材的世界里,她和一个人一起活下来、站上去,并且改变规则本身。

## 读者期待(不交付会弃书)
- **科技要有代价**:跃迁烧命、机甲反噬、基因改造有副作用——没有代价的科技等于许愿机。
- **身份要能反转**:她凭什么特殊(实验体 / 旧贵族 / 唯一适配者),这个身份必须一边给红利一边带来追杀。
- **双强或互补**:一个扛外,一个扛内;两人的能力要能拼在一起用。
- **世界规则明确**:星域、阵营、等级、禁令,读者要能排出"谁怕谁"。

## 必备桥段(选用,别全塞)
- **开场即脱轨**:匹配 / 联姻 / 征召 / 逃难,把一个普通人推进体制内。
- **第一次上机 / 第一次出舱**:生理与心理的极限体验。
- **阵营冲突**:两大势力的利益撞上,她被迫选边。
- **叛逃或抗命**:为了救人违反禁令,代价立刻兑现。
- **异种危机**:虫潮 / 叛乱 / 病毒,把私人矛盾压到生存矛盾下面。
- **改写规则**:公开真相、掀翻某个制度、或者带着人另立一边。

## 常见雷区(踩了掉粉)
- **科技许愿机**:缺什么就有什么,冲突全部失效。
- **恋爱脑压过世界观**:星舰要炸了还在吵架吃醋。
- **设定自相矛盾**:前面说不能跃迁,后面随便跃。
- **配角工具化**:队友只负责牺牲和欢呼。
- **名词轰炸**:堆一堆自造词,读者读三章不知道在讲什么。

## 金手指匹配
- **长什么样**:唯一适配的机甲 / 特殊基因 / 一段被封印的权限 / 能与异种沟通。
- **成长性**:从"能开机"到"能改造"到"能定义规则"。
- **必须有的限制/代价(防无敌)**:开机烧精神力,用久会残;身份越特殊越被通缉;与异种沟通会被同化;权限有等级门槛,越权即反噬。
