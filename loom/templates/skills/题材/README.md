## 复合题材
- 想糅两个题材:主辅 7:3,主线走主题材逻辑,副题材只供钩子/规则/爽点。最多两个。
- 例:修仙+系统流、古言+宫斗宅斗、都市脑洞+规则怪谈、诸天无限+系统流。
- 复合时把两份题材文件都拷进来,作者自己手动取舍。
