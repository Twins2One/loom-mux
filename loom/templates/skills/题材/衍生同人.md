# 衍生同人题材模板(晋江「衍生」· 起点女频「轻小说」)

> 给【设定师】读,用来圈这本书的剧情边界。管「写什么套路」(what),不碰「怎么写得像你」(voice)。
> 参考速查,不是铁律——和你的脑洞冲突时以你为准,直接手改。
> **平台说明**:
> · 晋江「衍生」频道二级 = 衍生纯爱 / 二次元言情 / 衍生言情 / 衍生无CP / 原创轻小说
> · 起点女频「轻小说」二级 = 同人衍生 / 唯美幻想 / 萌系变身 / 青春日常 / 搞笑吐槽 / 古典衍生 / 影视衍生 / 动漫衍生 / 其他衍生

## 核心爽感
读者已经在原作里爱过这些人,你要做的是"让他们再活一次",并且给出原作没给的那口气。

## 读者期待(不交付会弃书)
- **人物不能走形**:说话方式、行为逻辑、在意的东西要跟原作对得上;这是本类第一红线。
- **原作细节要准**:时间线、关键事件、专有名词,写错一处就会被指出来。
- **要动真格改剧情**:只做"日常番外"读三章就腻;必须有一条主线在推进或改写。
- **标注清楚**:哪部分是原作设定、哪部分是作者私设,读者需要能分辨。

## 必备桥段(选用,别全塞)
- **入局**:以什么身份进入这个世界(原作角色 / 新增角色 / 旁观者)。
- **第一次改变**:改掉一件原作里让人不甘心的事,蝴蝶效应立刻显现。
- **风险升级**:原作势力注意到异常,关系与处境同时变紧。
- **群体场面**:多人同场的大事件(决战、祭典、崩坏),给并肩与表态的机会。
- **代价兑现**:改动带来的反噬必须落到具体的人和事上。
- **收束**:改到底还是收手,给出明确选择。

## 常见雷区(踩了掉粉)
- **OOC**(人设崩):本类最致命,读者第一时间反弹。
- **梗堆砌没故事**:通篇玩梗,没有真正推进的主线。
- **原作设定写反**:把核心规则、能力上限、人物关系记错。
- **无限改剧**:想改就改、毫无反噬,紧张感归零。
- **私设不标**:读者分不清哪句是原作、哪句是你编的,信任直接崩。

## 金手指匹配
- **长什么样**:剧情记忆 / 系统 / 被原作规则承认的特殊身份。
- **成长性**:从"知道会发生什么"到"能影响"到"能改写规则"。
- **必须有的限制/代价(防无敌)**:记忆随改写失真;每次干预引来反噬(自身/关系/世界线修正);
  系统任务与发言有硬性约束;身份暴露即失去立足点。
