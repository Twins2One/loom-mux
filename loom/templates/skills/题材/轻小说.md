# 轻小说题材模板

> 给【设定师】读,用来圈这本书的剧情边界。管「写什么套路」(what),不碰「怎么写得像你」(voice)。
> 参考速查,不是铁律——和你的脑洞冲突时以你为准,直接手改。

## 核心爽感
一群立得住的人,把日常过得有意思。爽感来自角色与对话,不是来自战力数值。

## 读者期待(不交付会弃书)
- **角色属性要一眼可辨**:说话方式、行动逻辑、在意的东西,三个人站一起读者要能分清。
- **对话推动剧情**:轻小说的叙事主要靠"谁跟谁说了什么",而不是大段旁白铺设定。
- **单元剧节奏**:一个小事件 3~6 章收掉,长线埋在后面,别一口气铺世界观。
- **适当的轻松感**:吐槽、误会、日常段落是主菜,不是配菜。

## 必备桥段(选用,别全塞)
- **开局换环境**:转学 / 搬家 / 被召唤 / 同居 / 加入社团,把陌生人硬凑到一起。
- **第一次协作**:一件小事让他们不得不配合,顺手把关系定调。
- **误会喜剧**:信息差造成的错位,读者知道而角色不知道。
- **祭典或合宿**:脱离日常的场景,让关系推进一格。
- **单元事件收束**:小案子/小委托解决,附带一点长线线索。
- **揭底一幕**:某个角色的秘密露出一角,读者对长线产生兴趣。

## 常见雷区(踩了掉粉)
- **只有设定没有故事**:三章都在介绍世界规则,读者早走了。
- **吐槽过量**:每句都插科打诨,情绪永远沉不下来。
- **角色工具化**:配角只为推动剧情存在,没有自己的生活。
- **主线失踪**:写了十万字日常,读者不知道这本书到底要讲什么。
- **设定与日常脱节**:能力只在战斗时出现,平时毫无影响。

## 金手指匹配
- **长什么样**:特殊能力 / 系统面板 / 身份秘密 / 一支能说话的契约物。
- **成长性**:能力要能长,但增长方式偏"用法变多"而不是"数值变大"。
- **必须有的限制/代价(防无敌)**:能力要**给日常制造麻烦**(藏不住、会误触、有冷却);身份秘密怕被揭穿;系统条件苛刻到好笑。
