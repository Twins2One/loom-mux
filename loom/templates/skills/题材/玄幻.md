# 玄幻题材模板

> 给【设定师】读,用来圈这本书的剧情边界。管「写什么套路」(what),不碰「怎么写得像你」(voice)。
> 参考速查,不是铁律——和你的脑洞冲突时以你为准,直接手改。
> 这是**男频玄幻总纲**:东方玄幻 / 异世大陆 / 王朝争霸 / 高武世界 都从这份起手,再叠子类文件。

## 核心爽感
在这个世界,力量就是秩序。一个起点极低的人靠一次次"赢下不该赢的仗",把规则一层层踩到脚下。

## 读者期待(不交付会弃书)
- **等级体系要清楚且可预期**:读者要能在心里排出"谁能打谁",并且每次升级都立刻兑现成战力。
- **世界要够大**:一张图走完了就该换图,新地图要有新的强者、新的规则、新的天花板。
- **主角要有硬动机**:不是"我要变强"这种空话,而是被夺、被杀、被逐、被看不起的具体原因。
- **每 8~15 章要有一次可见的跃迁**:突破、得到底牌、翻盘、名声大涨,任选其一。

## 必备桥段(选用,别全塞)
- **开局立锥**:测资质 / 觉醒 / 家族试炼,当众被打压,埋下第一个"我得变强"的理由。
- **第一次越级反杀**:赢一场所有读者都以为他会输的架。
- **同门/同族欺压**:具体的人、具体的羞辱、具体的还击。
- **秘境或遗迹**:有门槛、有竞争者、有宝物、有代价。
- **换地图**:被追杀 / 主动远行 / 卷末大战后格局重排,主角带着名声进入更大的池子。
- **镇压级亮相**:忍了很久之后一次不留手的全灭,让读者结算前面的憋屈。

## 常见雷区(踩了掉粉)
- **体系含混**:等级名字一大堆但说不出强弱关系,战力立刻崩。
- **升级不爽**:突破了却看不到实际变强,或者要靠旁白反复强调"他现在很强"。
- **主角全程被动**:被推着走、被救、被安排——玄幻读者要的是主动进取。
- **金手指没代价**:无所不能等于没有张力,所有冲突都会失去意义。
- **换地图换丢人**:老配角全扔、老伏笔全断,读者会觉得"这书换了个作者"。

## 金手指匹配
- **长什么样**:体质 / 血脉 / 传承 / 一方小世界 / 吞噬或推演类异宝——要能"陪主角升境",不是一次性道具。
- **成长性**:分阶段解锁,每个阶段对应一个境界台阶,别一步到顶。
- **必须有的限制/代价(防无敌)**:越级有上限(只能压小境界,不能跨大境界)、使用要付寿元/精血/因果/冷却、越强越招眼(暴露即被围杀)。
