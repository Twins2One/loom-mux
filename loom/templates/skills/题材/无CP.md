# 无CP题材模板(晋江「无CP+」频道)

> 给【设定师】读,用来圈这本书的剧情边界。管「写什么套路」(what),不碰「怎么写得像你」(voice)。
> 参考速查,不是铁律——和你的脑洞冲突时以你为准,直接手改。
> **平台说明**:晋江「无CP+」二级 = 无CP小说 / 男主无CP / 女主无CP / 多元小说。起点无对应频道。

## 核心爽感
不谈恋爱,也能把人钉在屏幕前。爽感来自**事业、成长、复仇、探案、生存**,不是感情线。

## 读者期待(不交付会弃书)
- **主线要硬**:必须有一条能一句话说清的目标(查清真相 / 活下去 / 爬到顶),且每章都在推进。
- **人物关系是"关系"不是"暧昧"**:可以有羁绊、有并肩、有对手,但不许往恋爱上引。
- **别偷偷谈恋爱**:本类读者最反感的就是"标着无CP,三十章后亲上了"。
- **配角要有自己的生活**:不是等着被主角选中。

## 必备桥段(选用,别全塞)
- **起手一个坑**:把主角扔进一个非解决不可的处境。
- **能力或身份的第一次兑现**:让读者看到"她/他确实能干"。
- **组队或结盟**:为共同目标绑在一起,但关系止于"同盟"。
- **背刺或立场反转**:盟友变对手,把张力顶上去。
- **绝境方案**:资源见底时的一次狠招。
- **阶段性收束**:打完一仗、结掉一桩,再开新局。

## 常见雷区(踩了掉粉)
- **暗度陈仓**:标无CP却写感情戏,会被直接开骂。
- **主线失踪**:只剩日常和碎嘴,读者不知道这本书要干什么。
- **主角无敌**:没有阻力的成长等于没有故事。
- **配角降智**:为了突出主角把所有人写成蠢货。
- **情绪靠旁白喊**:不写具体动作与细节,只在旁白里说"她很愤怒"。

## 金手指匹配
- **长什么样**:系统 / 异能 / 特殊知识 / 一件关键物品。
- **成长性**:从"能自保"到"能改变局面"到"能定规则"。
- **必须有的限制/代价(防无敌)**:能力有明确边界与冷却;每次动用招来更大的敌人;
  系统条件苛刻;知识会过期或被封堵。
