# N次元题材模板(女频二次元)

> 给【设定师】读,用来圈这本书的剧情边界。管「写什么套路」(what),不碰「怎么写得像你」(voice)。
> 参考速查,不是铁律——和你的脑洞冲突时以你为准,直接手改。
> 综漫 / 同人 / 二次元穿越 都从这份起手。

## 核心爽感
进入那个世界,和喜欢的人并肩,并且**改掉原作里最不甘心的那一段**。

## 读者期待(不交付会弃书)
- **原作/类型的还原度**:人物说话的方式、标志性桥段、世界观规则,写歪一处就会被指出。
- **嗑点要准**:互动要落在读者想看的关系上(并肩、护短、互怼、托付),不是空撒糖。
- **改剧情的代价**:改变原著结局必须付代价,否则一切都不成立。
- **穿越理由站得住**:为什么是她、凭什么能进、进去之后是什么身份——开局就要交代。

## 必备桥段(选用,别全塞)
- **入界一幕**:穿越/觉醒/绑定,身份与限制同时给出。
- **初遇关键角色**:第一面就要留下记忆点,别流水账打招呼。
- **第一次干预**:改一件小事,蝴蝶效应立刻显现。
- **身份差点暴露**:紧张段落,把关系推近一格。
- **群体事件**:多人同场的大场面(祭典、决战、崩坏),给出并肩的机会。
- **终局选择**:留下还是回去,改到底还是收手。

## 常见雷区(踩了掉粉)
- **OOC**:原作角色说话做事不像本人,读者第一时间反弹。
- **梗堆砌没故事**:通篇玩梗,没有一条真正推进的主线。
- **穿越理由糊弄**:一句"莫名其妙就穿了",后面所有设定都立不住。
- **万能改剧**:想改就改,没有任何反噬,紧张感归零。
- **知识错位**:角色知道不该知道的事,却不解释来源。

## 金手指匹配
- **长什么样**:剧情记忆 / 系统面板 / 某种被原作规则承认的特殊身份。
- **成长性**:从"知道会发生什么"到"能影响发生什么"到"能改写规则"。
- **必须有的限制/代价(防无敌)**:记忆会随改写而失真;每次干预引发反噬(自身受伤/关系恶化/世界线修正);系统任务与发言有硬性约束。
